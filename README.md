### 📱 手机端打开方法
1. 手机连接 **和电脑同一个 Wi-Fi**（例：192.168.3.x 网段）；
2. 用手机相机 / 微信扫一扫下方二维码，或用手机浏览器打开 `http://192.168.3.99:8123`；
3. 手机浏览器如果提示「连接本地网络」请点**允许**；
4. 打开后点右下角 **🤖 悬浮按钮** 即可使用畜牧业智能体（支持语音提问）。
> 提示：局域网 IP 可能随路由器变化；如打不开，在电脑终端执行 `ipconfig getifaddr en1`（或 en0）查看最新 IP。

## 如何保持"一直在线"（已安装开机自启）
系统已配置**开机自启服务**（电脑开机就自动运行，掉线自动重连）：
```bash
cd /Users/Shared/aimuge-ranch        # 或到项目目录
./aimuge-services.sh start           # 启动（开机自动运行，一般不用手动）
./aimuge-services.sh stop            # 停止
./aimuge-services.sh url             # 查看最新公网网址（重启电脑后用它）
./aimuge-services.sh sync            # 改完系统文件后同步到运行目录
```
- 只要这台电脑开机、联网，公网网址就一直有效
- 电脑关机 → 网址打不开；重启电脑后运行 `./aimuge-services.sh url` 拿新网址
- 想永久固定网址：部署到云服务器（阿里云/腾讯云）或用花生壳

## 特性
- **畜牧业智能体**：侧边栏 / 手机右下角悬浮 🤖 进入；可问存栏、饲草、防疫、屠宰、订单、转场、天气等，回答基于系统实时数据；快捷问题一键提问；Edge/Chrome 支持语音
- **智能硬件自动采集**：内置实时采集引擎，天气/体温/圈舍/在线率/NDVI 等每 5 秒自动刷新（顶栏 ● 实时采集可开关）；智慧装备页标注每项指标的来源设备、协议、采集频率
- **每个栏目都可修改**：顶栏 ⚙️ 可修改任意栏目名称
- **每块数据都可改**：各台账支持新增 / 编辑 / 删除，实时联动总览与大屏
- **智慧装备端口对接**：ONVIF / GB28181 / RFID / 北斗 / LoRaWAN / Modbus / ISOBUS，市场主流设备即插即用
- **数据本地持久化**（localStorage），牧场档案页可一键重置示例数据
- 草原风格视觉：蒙古族菱形云纹、草原绿 + 哈达蓝 + 大地金配色

## 部署到公网（可选）
纯静态网页，部署到任意静态托管（GitHub Pages / nginx / 对象存储）即可：
```bash
sudo apt install nginx && sudo cp -r 本目录/* /var/www/aimuge/
```
浏览器访问 `http://服务器IP/` 即可给更多人参会演示。
